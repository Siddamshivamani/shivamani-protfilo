About the Project

This is a personal portfolio website developed using Python, FastAPI, HTML, CSS and Jinja2. The website provides information about me, my technical skills, educational qualifications and projects. It includes a responsive design that works on desktop, tablet and mobile devices. The portfolio also includes a dark and light theme switching feature using cookies without JavaScript.

Technologies Used

This project was developed using Python as the programming language and FastAPI as the backend framework. HTML is used to structure the web pages, CSS is used for styling and responsive design, and Jinja2 is used for template rendering. Cookies are used to remember the selected theme.

Features

The portfolio website includes a professional introduction, profile picture, About Me section, technical skills section, project showcase, education details and contact information. It also provides dark and light theme switching, responsive layouts and smooth navigation between website sections.

Installation and Setup

To run this project locally, clone the repository from GitHub and navigate to the project directory. Install the required dependencies using pip and start the FastAPI application using Uvicorn. After starting the server, open the application in your browser.

How to Run

Install the required packages using pip install fastapi uvicorn jinja2 and run the application using uvicorn main:app --reload. Open http://127.0.0.1:8000 in your browser to view the portfolio website.
